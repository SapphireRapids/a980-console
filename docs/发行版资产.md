# 发行版资产

编译好的可执行文件（v1.0.0）已随仓库提交，放在 `release/` 下：

| 文件 | 大小 | 说明 |
|---|---|---|
| `release/A980Console-1.0.0.exe` | 9,070,080 B | 主程序（Tauri v2 单文件，前端已内嵌，不联网） |
| `release/A980Console-1.0.0-setup.exe` | 2,800,419 B | NSIS 安装程序（per-user，无需管理员） |
| `release/a980-probe-1.0.0.exe` | 416,768 B | 命令行探针（`--verify` 写路径自检） |

三者均在 Windows 11 26200 主机上用本仓库源码 `cargo build --release` + `makensis installer.nsi` 构建，
并经过真机验收：鼠标（固件 1.2.1）连接后读回全量快照，DPI 五档 400/800/1600/3200/6400 当前第 4 档、
回报率 1000 Hz、灯区 effect 5/flag 0/speed 1/亮度 255、15 个按键、配置档 1，与基线一致；界面经 CDP 验证真实桥接、
内嵌前端为最终版（含颜色删除、无韩文）。

## 图标

`icons/` 下是原生二进制图标（32/128 PNG + 多档 ICO），`tauri.conf.json` 直接引用，无需解码。

## 依赖锁定

`Cargo.lock` 已提交，`cargo build --release` 按锁定版本复现上方三个产物。

## 自行构建

见 [README.md](../README.md) 的「编译」一节：

```bash
cargo build --release --bin a980-console --bin a980-probe
makensis installer.nsi
```
